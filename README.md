# OrganizationalStructure

Система управления организационной структурой компании с поддержкой иерархии подразделений и сотрудников.


## Описание проекта

**OrganizationalStructure** — веб‑приложение для управления организационной структурой предприятия. Позволяет:

* создавать и редактировать департаменты с иерархией (родительские/дочерние подразделения);
* управлять сотрудниками: добавлять, обновлять, фильтровать;
* просматривать структуру компании с заданной глубиной вложенности;
* выполнять мягкое удаление (soft delete) для департаментов и сотрудников;
* переназначать сотрудников при удалении департамента.

### Ключевые возможности

* **Иерархия департаментов**: поддержка неограниченной вложенности подразделений.
* **Гибкие запросы**: фильтрация и сортировка данных (сотрудники сортируются по `created_at`, `full_name`).
* **Мягкое удаление**: объекты помечаются как неактивные (`is_active = false`) вместо физического удаления.
* **Управление сотрудниками**: привязка к департаментам, обновление данных, фильтрация.
* **API**: RESTful‑интерфейс на FastAPI с типизацией через Pydantic.
* **Персистентность**: PostgreSQL как основная БД, SQLAlchemy ORM для работы с данными.
* **Контейнеризация**: запуск в Docker, управление через `docker-compose`.

## Технологии

* **Backend**: FastAPI (Python)
* **ORM**: SQLAlchemy
* **Модели данных**: Pydantic
* **База данных**: PostgreSQL
* **Контейнеризация**: Docker, Docker Compose
* **Миграции БД**: Alembic

## Запуск проекта
* Клонировать репозиторий
git clone https://github.com/Godzilka213/OrganizationalStructure.git

cd OrganizationalStructure
* Запустить проект
docker-compose up --build

После запуска приложение будет доступно по адресу:

http://localhost:8000

Swagger документация:

http://localhost:8000/docs

Redoc:

http://localhost:8000/redoc
Переменные окружения

Создать .env файл:

- DB_HOST=db
- DB_PORT=5432
- DB_NAME=org_structure
- DB_USER=app_user
- DB_PASSWORD=secret_password
